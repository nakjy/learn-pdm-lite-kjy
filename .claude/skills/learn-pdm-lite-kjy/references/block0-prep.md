## EXPLAIN

### 1. 오늘 쓰는 데이터

| 용어 | 뜻 |
|---|---|
| 다변수 센서 데이터 | 진동·온도·압력처럼 여러 변수를 동시에 시간 순으로 기록한 것 |
| 진동 (mm/s) | 베어링·회전체 마모, 정렬 불량을 본다. 갑작스러운 증가·추세적 상승이 전조 |
| 온도 (℃) | 마찰·과부하·윤활 부족을 본다. 서서히 오르는 흐름이 위험 신호 |
| 압력 (bar) | 유압·공압 계통 누출·막힘을 본다. 평상 범위 이탈 구간을 표시 |

실습 파일은 강의 저장소의 `Day5_설비센서_50건_가상.csv` — 설비A(프레스 메인모터)와 설비B 두 대 × 25시점(20분 간격), **가상 데이터**다.

### 2. 왜 단위부터 보는가

| 기준 | 바로 계산 | 단위 먼저 확인 |
|---|---|---|
| 결과 | 단위가 섞이면 정상값도 이상처럼 보인다 | 같은 단위끼리 비교해 판단이 흔들리지 않는다 |

원본 덱(② 데이터): "단위(℃, mm/s, bar)와 측정 주기를 먼저 확인한다 — 단위가 섞이면 이상 판단이 흔들린다."

### 3. 케이스 — 1분 멈춤이 수천만 원

조립 라인은 한 곳이 멈추면 뒤 공정이 줄줄이 멈춘다. 라인 정지 1분 손실이 수천만 원 — "고장을 미리 아는 것"이 생존의 문제다(원본 덱 p6).
