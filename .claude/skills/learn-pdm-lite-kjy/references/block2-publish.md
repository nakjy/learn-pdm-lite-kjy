# Block 2: 공개 — 그래프를 GitHub Pages로

> **Phase A 시작 시 그대로 출력한다:**
> ```
> 📖 공식 문서: https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site
> ```

## EXPLAIN

### 1. 정의

| 용어 | 뜻 |
|---|---|
| GitHub 저장소 | 파일과 변경 기록을 올려 두는 온라인 폴더 |
| GitHub Pages | 저장소의 `index.html`을 웹 주소로 보여 주는 무료 기능 |

### 2. 왜 공개 주소로 남기는가

| 기준 | 내 PC의 파일 | 공개 주소 |
|---|---|---|
| 공유 | 파일을 따로 보내야 한다 | 링크 한 줄로 동료가 바로 본다 |

### 3. 공개 전 보안 수칙

- 공개 저장소에는 **가상 데이터와 그래프만** 올린다. 회사 설비 데이터·개인정보는 올리지 않는다.
- GitHub 비밀번호·토큰은 대화창에 붙여 넣지 않는다. 로그인은 브라우저에서 직접 한다.
- 그래프 아래 "가상 데이터"와 출처 표기가 있는지 확인한다.

## EXECUTE

아래 프롬프트를 붙여 넣으라고 안내한다.

```
pdm-lite 폴더의 그래프를 GitHub Pages로 공개해 줘.
1. 공개 전에 올릴 파일 목록을 보여 주고, 비밀값·개인정보가 없는지, index.html 에 "가상 데이터"와 출처 표기가 있는지 점검해 줘.
2. git 저장소로 만들고 index.html, anomaly.csv, data/ 를 커밋해 줘.
3. GitHub 에 pdm-lite 공개 저장소를 만들고 올린 뒤 GitHub Pages(main 브랜치, 루트)를 켜 줘. gh 로그인이 필요하면 브라우저 로그인 방법만 안내하고 기다려 줘.
4. 비밀번호나 토큰을 나에게 묻지 마.
5. 공개 주소를 알려 줘.
```

수강생이 직접 할 일:

1. GitHub 로그인 창(브라우저)이 뜨면 직접 로그인하고 승인한다.
2. 1~2분 뒤 공개 주소를 브라우저에서 열어 그래프가 보이는지 확인한다.

### 확인할 것 (Phase B)

- 공개 주소가 열리고 진동 그래프 한 장이 보인다.
- 저장소에 비밀값·개인정보 파일이 없다.
- 그래프 아래 "가상 데이터"와 출처가 보인다.

막히면 "Pages 주소가 안 열리는 원인을 찾아 줘"라고 붙여 넣게 한다.
